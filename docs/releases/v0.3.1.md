# RepoPilot v0.3.1 — npm README update

The npm package now uses the current repository README, including `npm install -g repilot`,
command aliases, EULA acceptance, and setup instructions. Packaging converts relative documentation
links and demo image URLs to links pinned to the release source commit so they render on npm.
The separate npm usage guide remains documentation, rather than a second source for the package README.

```bash
npm install -g repilot@0.3.1
repilot --license
# Only if you agree to EULA v1.0:
export REPOPILOT_ACCEPT_EULA=1
repilot version
```

This is a documentation/packaging patch release. The release workflow runs full checks and archive
smoke tests on Linux and macOS, publishes the validated Linux archive through npm trusted publishing,
and verifies registry availability, distribution tag, and archive integrity after npm processing.
